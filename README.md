# Aperant Desktop releases

This repository holds **release assets only**: installers and the auto-update
feed files (`latest.yml`, `latest-mac.yml`, `latest-linux.yml`, and their
`beta*` counterparts). It contains no source code.

Aperant Desktop's auto-updater reads its feed from the releases published here.
Releases are created by the release workflows in the (private) source
repository. Please do not commit anything to this repository by hand.

Download the latest version from the [Releases page](https://github.com/Mikalsen-AI/aperant-releases/releases/latest).
